# 📚 University Study Notes

Welcome to my University Study Notes Library!

This repository contains organised notes, important concepts, formulas, worked examples, and revision materials for my university studies.

## 📖 Subjects

### 📊 Statistics

Notes covering probability, descriptive statistics, estimation, hypothesis testing, confidence intervals, and other statistical concepts.

### 💰 Economics

Notes covering microeconomics, consumer theory, production, costs, market equilibrium, and monopoly.

### ➗ Mathematics

Notes covering matrices, linear algebra, differential equations, and other mathematical concepts.

## 🎯 Goals of This Project

* Organise my university study notes in one place.
* Improve my understanding of important concepts.
* Keep worked examples for future revision.
* Track my learning progress.
* Build a useful personal study resource.

## 📝 How the Notes Are Organised

Each subject has its own folder. Individual topics are stored in separate Markdown files.

Where appropriate, the notes include:

* Definitions and explanations.
* Important formulas.
* Step-by-step worked examples.
* Common mistakes to avoid.
* Practice questions.

## 🚧 Project Status

This project is a work in progress. New topics and improvements will be added as I continue learning.
