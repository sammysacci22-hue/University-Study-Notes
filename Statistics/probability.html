🎲 Introduction to Probability

Understand the basics, learn the formulas, and practise solving probability problems step by step.

1. What is probability?

Probability measures how likely an event is to happen. Its value lies between 0 and 1.

  • 0: The event is impossible.
  • 0.5: The event has a 50% chance.
  • 1: The event is certain.
0 ≤ P(A) ≤ 1

Here, P(A) means the probability that event A occurs.

2. Important definitions

Experiment

An action that produces an outcome, such as rolling a die.

Sample space

The set of all possible outcomes of an experiment. For a standard six-sided die:

S = {1, 2, 3, 4, 5, 6}

Event

A collection of outcomes that satisfy a particular condition. For example, rolling an even number gives:

A = {2, 4, 6}

3. The basic probability formula

When all outcomes are equally likely, divide the number of favourable outcomes by the total number of possible outcomes.

P(A) = Number of favourable outcomes / Total number of outcomes

Worked example

A fair die is rolled. Find the probability of obtaining an even number.

Step 1: List all possible outcomes.

S = {1, 2, 3, 4, 5, 6}

Step 2: Identify the favourable outcomes.

A = {2, 4, 6}

Step 3: Count the outcomes.

Favourable outcomes = 3

Total outcomes = 6

Step 4: Apply the formula.

P(A) = 3/6 = 1/2 = 0.5

Answer: The probability is 0.5, or 50%.

4. Important probability rules

Complement rule

The complement of A means that A does not occur.

P(A') = 1 − P(A)

Addition rule

For two events A and B:

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

The intersection term is subtracted because outcomes common to both events would otherwise be counted twice.

Multiplication rule for independent events

If A and B are independent, the occurrence of one does not change the probability of the other.

P(A ∩ B) = P(A) × P(B)

5. Common mistakes to avoid

  • Counting the total possible outcomes incorrectly.
  • Confusing favourable outcomes with total outcomes.
  • Using the multiplication rule without checking independence.
  • Forgetting to subtract the intersection in the general addition rule.
  • Giving a probability smaller than 0 or greater than 1.

6. Practice questions

  1. A fair die is rolled. Find the probability of obtaining a number greater than 4.
  2. A fair coin is tossed once. Find the probability of obtaining tails.
  3. A card is selected from a standard deck of 52 cards. Find the probability of selecting an ace.
  4. If P(A) = 0.35, find the probability that A does not occur.

Study tip: Try each question yourself before checking your notes.
